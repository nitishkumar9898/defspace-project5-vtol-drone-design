🎯 Project Objective

Design a quadrotor VTOL UAV capable of stable hover and autonomous flight. The project covers frame selection, propulsion system sizing (motor + propeller + battery), flight controller configuration, and performance estimation. Target payload: 200g camera/sensor package. Mission: aerial survey at low altitude (<50m AGL).

🔩 Structural Considerations

  • ✅ Carbon arms rated >50N tip load each
  • ✅ Vibration isolation: FC on 3M foam tape
  • ✅ Landing gear rated for 5× AUW impact
  • ✅ Battery strap rated 3× battery mass
  • ✅ Motor mounts with thread-lock on all bolts

⚡ Power Distribution

  • 🔴 Battery → PDB (14AWG silicon wire)
  • 🔴 PDB → 4× ESC (16AWG)
  • ⚡ UBEC → Flight controller 5V rail
  • 📡 FC → Receiver via S.Bus
  • 📡 FC → Telemetry via UART
